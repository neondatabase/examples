# with-realtime-chat (web)

This is the Next.js frontend for the realtime chat example. It uses Neon Auth for sign-in and talks over WebSockets to the Hono server that runs on Neon Functions.

This app is not meant to be run on its own. Follow the setup and run steps in the [parent README](../README.md), which covers the server, the database, and this web app together.

# with-realtime-sse (web)

This is the TanStack Router SPA (Vite and React) for the realtime SSE example. It talks over server-sent events to the Hono server that runs on Neon Functions.

This app is not meant to be run on its own. Follow the setup and run steps in the [parent README](../README.md), which covers the server, the database, and this web app together.
